# 豪密 · 密码纪念馆

展示纪念版，简体中文界面，支持桌面与手机。

在线访问：[豪密 · 密码纪念馆](https://cochranek.github.io/HaoMi/)。

- 豪密历史时间线、人物与资料来源。
- 书本索引、底本＋乱数两个明确标注的教学模型。
- 02 保留豪密教学；03 默认打开豪密思路的数字密语工具，可加密实际文本、复制/保存密文与配套密钥，刷新后粘贴或导入密钥文件解密。中文原文、英文、符号、空格和换行均完整保留。
- 凯撒、Vigenère、栅栏、一次一密、AES-GCM、RSA-OAEP、摩斯、Base64、SHA-256 九种互动实验继续保留；桌面以十行列表选择，手机豪密置顶、其余九项为 3×3。经典过程可分页，过程与结果可并排或展开查看。
- 用户原创扑克规则：中文转拼音、英文直接映射、红黑 Joker 小丑对应标点、数字码反解、拼音校正、花色切换、SVG 导出；网页和导出使用同一套小丑矢量图案。
- 输入和密码运算在浏览器中完成；无输入内容上传接口。字体从 Google Fonts 加载，字体不可用时回退系统字体。拼音字典已打包到本地资源。

详见 [调研报告](RESEARCH.md)。展览教学模型不等同于原版豪密复原。中文扑克码反解得到拼音，不能唯一恢复汉字。

## 本地运行

```sh
npm ci
npm run build
npm test
npm run dev
```

打开 `http://127.0.0.1:4173`。`dist` 是完整静态页面，需要 HTTP 服务以加载 ES modules；直接双击 `index.html` 可能受浏览器模块策略限制。

## GitHub Pages 发布

向 `main` 分支推送后，GitHub Actions 自动安装依赖、构建本地拼音字典、执行密码验证，再把 `dist` 发布到 GitHub Pages。也可以在 Actions 页手动运行 `Deploy GitHub Pages`。

页面资源使用相对路径，兼容 `/HaoMi/` 仓库子路径。Pages 发布使用 HTTPS，支持浏览器中的 AES、RSA 与剪贴板功能。

## 实现参数

AES 使用 256 位密钥、96 位随机 IV、128 位认证标签。RSA 使用 2048 位密钥和 OAEP-SHA-256，单次限制 190 个 UTF-8 字节。密钥只保留在当前页面内存，用于加密教学与还原验证。

扑克映射为固定替换编码：`R01–R13` 对应 A–M，`B01–B13` 对应 N–Z，`BIG` 对应句号，`SMALL` 对应逗号。`/` 与 `NL` 是间隔标记，`U+码点` 是规则外原文保留标记。

牌面按逗号、句号、问号、叹号、分号或换行分组，分隔标点留在前一组内。支持三种展示：默认“手牌全貌”不抬起任何牌，长句的全部牌面分段直接展示；“逐张查看”可点选或滑动抬起单张，长句每次翻看 24 张；“平铺序列”完整展示每张牌及间隔标记。超过 6 组时先折叠显示，数字码与 SVG 导出始终包含完整序列，导出跟随当前扇形或平铺样式。空格仍保留在数字码与句子文字中。

密码实验室支持最多 8000 个输入字符，完整运算结果始终保留。凯撒、Vigenère、栅栏和摩斯过程图可分页查看所有转换字符，可直接输入页码跳转；Vigenère 密钥和栅栏路径跨页连续，摩斯试听对应当前段。AES、一次一密的流程文字与 Base64 的字节示例明确标注节选。RSA-2048/OAEP-SHA-256 单次仍限 190 个 UTF-8 字节，界面直接显示该限制。

过程图使用紧凑横向字母格。电脑端凯撒、Vigenère、摩斯每段展示 48 个字符，栅栏每段 64 个；手机端分别为 24、32 个。电脑端可用“展开过程 / 恢复并排”切换过程全宽和结果并排视图，工作区高度保持不变；手机过程面板固定为 340px，长过程在面板内纵向查看，分页按钮保留在底部。

03 的豪密思路工具将每个 Unicode 码点转成 7 位十进制自编底码，与浏览器生成的均匀随机数字逐位模 10 相加。输入停顿 180ms 后自动产生数字密文与新配套乱数；中文输入法组合完成后才处理。密文与密钥填好或导入后自动解密。输入变化会立即清空旧结果并取消旧任务，避免把旧密文配给新输入；翻页和窗口变化只调整过程视图，不换乱数。可用“换一份乱数”为相同输入再生成一组结果。此方案是本展自编的思路应用，不是历史原版豪密。

数字密文按 7 位分组，空格和换行仅用于排版。配套密钥 JSON 使用 `format: haomi-digital-key`、`version: 1`、`encoding: unicode-codepoint-7`，包含等长 `mask`、密文 `cipherDigest` 和原文 `plainDigest` 两个 SHA-256 校验值。导入时验证格式与长度，再核对密文和还原文字，识别拿错密钥、截断或改动；校验值不构成数字签名或消息认证。密文与密钥分别导出，页面不保存到本地存储，也不上传输入。再次打开网页后可使用保存的两份数据还原，不依赖原页面内存。
